# Tủ Sách Gia Đình

Trang đọc truyện trực tuyến tĩnh, giao diện tối ưu cho người lớn tuổi đọc trên điện thoại và máy tính.

---

## Tính năng

- Tùy chỉnh cỡ chữ nhanh từ thanh công cụ.
- Bốn chế độ màu nền dịu mắt: Giấy vàng Sepia, Sáng, Tối, Đen OLED.
- Tự động ghi nhớ tiến độ đọc của từng tác phẩm trên trình duyệt.
- Hỗ trợ xem mục lục, tìm kiếm theo tên tác phẩm và phân loại thể loại.
- Hoạt động trực tiếp trên nền tảng GitHub Pages mà không cần máy chủ phụ trợ.
